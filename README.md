# Опушка

Спокойная игра про лес и деревню. Godot 4.3, Android.

Время идёт только от действий: отложил телефон — мир замер. Собираешь ветки и камни,
делаешь инструменты, рубишь лес, строишь дом. Ночью темнеет, у костра светло.

Сборка: каждый пуш в `main` собирает APK в GitHub Actions и выкладывает его в релиз `build-N`.
