# Эволюция

Игра про развитие с одной клетки. Godot 4.3, Android.

Плаваешь в первичном океане, ешь водоросли или других, растёшь. Части тела — жгутики, шипы,
челюсти, клыки, панцири, глаза, яд, ток — выпадают из тех, у кого они есть, и не всегда.
Из них в редакторе собираешь своё существо: кем быть — хищником, травоядным или всеядным —
решает рот.

Сейчас готов первый этап — клетка.

Сборка: каждый пуш в `main` собирает APK в GitHub Actions и выкладывает его в релиз `build-N`.
